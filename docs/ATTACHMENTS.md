# 在手机上发送附件

每条消息最多带 **9 张图片、4 个文档**。相册可以多选，拍照会追加到同一份草稿。发送前可逐项移除。点已发的缩略图可全屏查看，双指缩放，左右滑动浏览同一条消息里的图片。点文件名可重开本机保存的正文或扫描页。

| 文件 | 手机如何读取 |
| --- | --- |
| TXT、Markdown、CSV、TSV、JSON、YAML、日志及常见代码文件 | 读取 UTF-8 或带 BOM 的 UTF-16，保留换行、制表符和缩进。代码包括 C/C++、Java、Kotlin、Python、JavaScript、TypeScript、Go、Rust 和 Shell 等。 |
| DOCX、XLSX、PPTX | 解开 Office 压缩包，提取正文段落、工作表单元格或幻灯片文字。电子表格读取已保存的单元格值。 |
| PDF | 在设备上提取前 64 页的文字，遇到单页超过 16,384 个字形时截断。若这些页都没有可提取的正文，用 Android 渲染器把前 **最多 3 页**转成 JPEG。每页占一个图片名额，还剩一个名额时只取第一页。 |
| 旧版 DOC | 可读取以 .doc 为后缀保存的纯文本。Word 97–2003 二进制文档需先另存为 DOCX。 |

单个文档最多 16 MiB。Office 包最多 2,048 个条目，所读 XML 解压后合计最多 24 MiB。每个文档本机保留最多 131,072 个 UTF-16 单元的正文前缀，截断处标记「…」。扫描件保存实际选中的页面。相册图片、相机照片和扫描页按长边最多 1,600 像素、每张最多 768 KiB 保存。重启后从应用私有目录加载缩略图，并清理上次导入中断留下的临时原件。删除对话也会清理其草稿和独占附件，共享文件保留到最后一个引用被移除。

## 发送给 DSH 的内容

手机将问题、以 `[文件：文件名]` 开头的正文块、JPEG 图片按顺序装入**同一个** `session/prompt`。文件解析在手机上完成，DSH 收到提取的文字和选中的图片，再交给当前模型。扫描页需要支持图片的模型，此流程不做本地 OCR。

文件正文合计最多发送 **64 KiB UTF-8**，同时受当前模型发送前触发值的四分之一和实际剩余空间限制。先预留问题、文件名和每张图的估算用量，再按现有策略压缩并重新计量。短文件可完整保留，长文件平分余量，从开头按完整 Unicode 字符截取。本机预览保留提取时的长度。后续压缩保留首轮和最近四轮，区间内的旧文件正文随该轮摘要，已处理的旧图由 DSH 按图片序号卸载。[上下文策略](CONTEXT.md)

# DeepSeek Harness 集成模块（用户 2026-11-23 原文）

目标： 将 DeepSeek Harness 作为 App 的核心 AI 接入方式，让用户通过自己的 DeepSeek 账号聊天，使用账号实际可用的额度。

功能要求：
1. 支持 DeepSeek 官方账号授权登录与退出。
2. 优先复用 DeepSeek Harness 官方账号和模型调用组件。
3. 显示账号余额、可用模型及登录状态。
4. 支持流式文字回复和连续多轮对话。
5. 支持图片输入
6. 运行时及聊天数据尽量保存在手机本地。
7. 不需要自行部署云端服务器。

开发前必须验证：
- Android 本地能否成功运行 Harness SDK。
- 是否能够完成官方账号授权。
- 聊天消耗是否从预期的 DeepSeek 额度扣除。
- 能否正常接收流式响应并保持聊天记录。

其他模块不变： 原生聊天界面、多模态输入、Markdown 渲染、语音朗读、本地历史记录及后续交互组件。

（早先要求仍有效：自动导入网页端以前的聊天并可继续聊；App 内充值或跳转网页充值。）

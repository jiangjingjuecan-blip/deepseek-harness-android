# 文游存档与分支

长按消息或点气泡旁的「⋯」，可存档、开分支或编辑。顶栏的「分支」列出这段对话的线路，勾号标出当前线路。面板下方列出当前线的存档，点一条即可回到对应消息。新分支保留选中消息及之前的内容。

## 回复版本

- 对最后一条 AI 回复点「重生成」，会从原问题生成一个新版本。箭头旁的数字表示当前版本和总数。每个版本都能继续写，切换时会一并打开该版本上次使用的线路及后续消息。
- 编辑 AI 回复会保存新文本和新线路。编辑用户消息会从原消息之前分出新线，保留旧问题、旧答案和后续剧情。保存后点发送可为改过的问题生成回答。编辑本身可以离线完成。
- 分支共享已经保存的附件文件。编辑用户消息会保留原来的照片、文档正文、图号位置和图片顺序。重生成会从本机重新读取原问题的附件，通过发送预算决定本轮可用的文档字节和图片数。已知原轮预算时，重发沿用其上限。AI 回复只保存文字。输入框的文字和附件草稿各属一条线路。

## 骰子

在输入框下点「骰子」，可以直接点 d4、d6、d8、d10、d12、d20、d100，或输入 `2d6+1`、`3d10-2`。每次可掷 1 至 100 颗，修正值的绝对值最多 99999。每颗独立取 Android `SecureRandom.nextInt(面数) + 1`，使用系统提供熵的密码学安全随机数生成器。

掷骰立即生成本地卡片。下一次发送时，连续的骰点按发生顺序各占一行，然后接玩家原文。例如，掷出 3 和 4 后发送「试着开锁」，模型收到的用户文本为

```text
[骰子 2d6+1 | 3,4 | 8]
试着开锁
```

单独点发送也能提交待判定的骰点。卡片记录的是当时的实际点数。重新打开、重生成、改写问题和从卡片开分支都会复用这些点数。后续轮次通过原问题的上下文看到它们。

## SQLite 7

| 数据 | 保存方式 |
| --- | --- |
| 对话与线路 | `chat` 保留标题和排序。`branch` 保存对话内的线路编号、当前选择、草稿与 DSH 会话。每个对话同时只有一条选中线。 |
| 消息与版本 | `branch_message` 按消息 ID 记录一条线的有序前缀。分支时只复制引用。`message` 保存角色、正文、状态、版本组、初始线路、实际附件预算及 DSH 事件位置。`version_visit` 记录某个版本上次使用的线路。 |
| 存档与骰子 | `save_point` 引用线路中的具体消息版本。分支复制前缀里的存档，之后可分别取消。`dice` 角色的消息持久保存骰式、每颗点数和总数。 |
| 附件与计量 | `attachment`、`attachment_file` 保存附件及文档图号偏移，未发送的附件绑定草稿线路。`context_meter` 单独记录每条线的窗口与占用。 |

从版本 6 升级时，原对话各自成为主线。迁移保留聊天和消息 ID、原 DSH 会话、用量、草稿、文档及图片路径。切分支、产生新版本、移动草稿附件和删除对话均通过 SQLite 事务完成。删除会清除对话下全部线路、版本、骰点、存档与附件记录。本机文件等到最后一个引用消失后移除，可在重启后补做。应用对已连接的 DSH 发起会话归档，范围包括该对话曾创建的恢复会话。[数据库实现](../app/src/main/java/com/sunwin/deepseekharness/History.java)

## DSH 会话与压缩

DSH 0.2.2-rc.2 的 `session/fork` 接受含端点的 `atSeq`。应用从流事件记录用户输入及其运行时上下文的位置，并在成功回复时记录 `turn/end`。新线首次发送或压缩时，应用从分支前缀中最近的有效事件创建独立会话。即使源线后来继续聊天或压缩，切点仍指向原日志。重生成从原问题之前分出会话，再提交该问题一次。[官方分支协议](https://github.com/deepseek-ai/deepseek-harness/blob/ddac9676/packages/api/session-controller/src/types.ts#L309-L321) · [官方日志切分](https://github.com/deepseek-ai/deepseek-harness/blob/ddac9676/packages/core/session/src/fork.ts)

旧库只有会话 ID。首次需要切分旧前缀时，预设依次核对原始用户消息、对应回复的正文摘要及轮次结束状态，用匹配到的日志位置原生分支。如果历史只有本地副本、回复经过编辑或发生过中断，则在独立会话中按原角色补入所选线路的文字。恢复沿用同一 persona、首轮顺序和 DSH 生成的运行时上下文。旧附件在这种文字恢复中保留文件标签、正文、`[图 N]` 与图片位置，图片用名称占位。恢复通过本地维护轮写日志，空维护轮在模型步骤前结束。切换回已有线路会复用该线自己的会话。[手机预设](../app/src/main/assets/phone-context.cjs) · [发送与恢复](../app/src/main/java/com/sunwin/deepseekharness/ChatEngine.java)

每次正式发送前先计量当前线的上下文，草稿计入待发送的骰子块和附件预算。手动或自动压缩只操作这条线的 DSH 日志，保留完整首轮及最近四轮，中段用该线自己的滚动摘要替换。已纳入用户轮次的骰点和当前版本文字随该轮参与压缩。SQLite 中的原文与存档继续保留。[上下文策略](CONTEXT.md)
